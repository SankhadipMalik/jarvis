# 🎙️ Jarvis – Voice Controlled AI Assistant

## 📌 Overview

Jarvis is a **voice-controlled AI assistant** that performs various tasks such as web browsing, music playback, information retrieval, and AI-based responses.

It uses speech recognition and text-to-speech technologies to create an interactive hands-free assistant experience.

---

## 🎯 Objective

To build a personal AI assistant capable of:

* Understanding voice commands
* Performing real-world tasks
* Providing intelligent responses

---

## ⚙️ Technologies Used

* Python
* SpeechRecognition (Voice Input)
* gTTS & pyttsx3 (Text-to-Speech)
* Pygame (Audio playback)
* OpenAI API / LLaMA (AI responses)
* Wikipedia API
* News API
* Webbrowser module

---

## 🧩 System Workflow

1. System listens for wake word **“Jarvis”**
2. Activates and listens for user command
3. Processes the command
4. Executes task or generates response
5. Speaks back the result

---

## 🔍 Key Features

* 🎤 Voice command recognition
* 🔊 Audio responses (AI voice output)
* 🌐 Open websites (Google, YouTube, LinkedIn, etc.)
* 🎵 Play music from custom library
* 📰 Fetch latest news
* 📚 Wikipedia-based information search
* 🤖 AI-based responses using LLM
* 🔁 Continuous listening system

---

## 📊 Example Commands

* “Jarvis, open YouTube”
* “Jarvis, play skyfall”
* “Jarvis, what is artificial intelligence”
* “Jarvis, tell me the news”

## ▶️ How to Run

### Step 1: Install dependencies

pip install speechrecognition pyttsx3 gtts pygame wikipedia requests

### Step 2: Add API keys

* OpenAI API key (optional)
* News API key

### Step 3: Run the program

python main.py
